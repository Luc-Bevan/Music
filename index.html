Fonctionnalités

Pensé pour des résultats parfaits

Une intelligence artificielle qui comprend vraiment vos fichiers — pas juste leurs noms.

🧠

L'IA lit le contenu

L'IA analyse le texte, les images, le code et même l'écriture manuscrite pour identifier de quoi parle chaque fichier — bien au-delà du nom.

✍️

Manuscrits maîtrisés

Modèles vision spécialisés et OCR multi-passe pour lire l'écriture cursive : devoirs, notes de cours, cahiers scannés. Le sujet est identifié même quand le texte n'est pas parfait.

🗂️

Arborescence intelligente

L'IA crée elle-même les dossiers thématiques et range chaque fichier au bon endroit. Plus de "Mes_documents_2023_v_final_final" qui traîne.

🔒

Privé par conception

Modèles IA exécutés localement sur votre machine. Aucune donnée envoyée à des serveurs tiers. Vos fichiers sont supprimés du dossier de travail après export.

📦

Tous les formats

PDF, Word, Excel, images (JPG, PNG, scans), code (.py .js .cpp…), archives (.zip, .rar), texte, notes Obsidian. Jusqu'à 1 Go par session.

✏️

Vous gardez la main

Un explorateur intégré laisse vérifier, renommer, déplacer ou regrouper avant l'export final. Recherche, tri, sélection multiple — comme un vrai gestionnaire de fichiers.

Questions fréquentes

FAQ

Mes fichiers sont-ils envoyés sur Internet ?
Non. SortDocAI tourne entièrement sur votre machine grâce à Ollama (IA locale). Aucun fichier, aucun texte extrait n'est envoyé vers un serveur tiers.
Quelle configuration minimum pour faire tourner l'app ?
Windows 10/11 ou Linux, 16 Go de RAM minimum (32 Go recommandé), un GPU NVIDIA avec 8 Go de VRAM idéalement (RTX 3060/4060+). Sans GPU, ça marche mais c'est plus lent.
Combien ça coûte ?
C'est gratuit. Le projet est open et l'inférence se fait sur votre machine — donc pas de coûts serveur.
L'IA lit-elle vraiment les manuscrits ?
Oui — SortDocAI combine plusieurs moteurs : EasyOCR optimisé pour le cursif, Tesseract, et le modèle vision spécialisé minicpm-v. Pour les manuscrits difficiles, l'IA identifie le sujet (math, philosophie…) même si la transcription verbatim n'est pas parfaite. C'est suffisant pour classer le fichier correctement.
Quelle est la limite de taille ?
1 Go par session de traitement, soit typiquement 500 à 2000 fichiers selon leur taille moyenne. Pour des batches plus gros, traitez en plusieurs sessions.
